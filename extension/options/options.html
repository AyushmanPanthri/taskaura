How It Works

  1. You add distraction domains to your blocklist (in the popup or here).
  2. When you start a focus session in TaskAura, this extension detects it within 30 seconds via a background poll.
  3. While your session is running, navigating to any blocked domain redirects you to a reminder page inside this extension.
  4. When your session ends (completed or abandoned), blocking lifts automatically within 30 seconds.
  5. Your blocklist is stored on the TaskAura server — it's the same across all browsers where you install this extension and log in with the same account.

⚠️ What This Tool Does Not Guarantee

This is a friction and commitment tool, not a technical lock. Please read these limitations before relying on it for accountability:

  • You can disable or uninstall this extension at any time. Browsers are under user control — no extension can prevent its own removal. Uninstalling this extension mid-session has no effect on your XP or session outcome.
  • Blocking is per-browser. Switching to a different browser, a private/incognito window where this extension is not active, another device, or your phone bypasses the block entirely.
  • Your session XP is not affected by bypass. XP eligibility is calculated entirely server-side based on when your session started and how many heartbeats were recorded — independently of whether this extension was active, disabled, or respected.
  • This extension is an enhancement, not a requirement. Users who never install it can use focus sessions and earn XP normally.

If you need stronger accountability, consider sharing your session goals with another person — social accountability is more reliable than technical controls for this use case.

About

TaskAura Focus Guard is a companion extension for the TaskAura productivity app. It is open source and its code can be inspected at any time from the Extensions menu → Manage Extensions → Source. No data is collected beyond what your TaskAura account already stores. Domains in your blocklist are stored on the TaskAura server, scoped to your account, and deleted when you remove them.
